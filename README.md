# Sum up 23 November's world news in one image

One newspaper front page that sums up Monday 23 November 2026, built for
the make.fun bounty
["Sum up 23 November's world news in one image"](https://make.fun/bounty/news-image-20261123).

## The image

The front page leads with burning tankers in the Strait of Hormuz, and
inside it carries the day's other big stories: the COP31 climate talks
falling apart, drones over Libya, Russian missiles landing in Poland, and
the Democrats winning Congress. The image is `output/entry.png`
(1024×1024), drawn as a classic broadsheet: a heavy masthead, one dominant
headline, and the rest of the news arranged around it.

## Run it

```sh
python3 main.py
```

The program uses only the Python standard library. It copies the
committed `output/entry.png` into the directory the grader provides
(`MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`), and exits 0 once a
copy has landed. No network access and no third-party packages are needed.
